# 电影级镜头语言

目标是让每一镜「像被拍下来的」，而不是「像被画出来的」。三条底层判断：**空间成立、光有方向、动作有因果**。缺任一条，观众立刻觉得是 PPT。

## 一、景别：不是大小，是信息量与情绪距离

| 景别 | 英文 | 主要交代 | 情绪距离 | 典型时长 |
| --- | --- | --- | --- | --- |
| 大远景 | extreme wide shot | 环境尺度、人与世界的关系、孤立感 | 最远 | 4~8 秒 |
| 远景 | wide shot | 空间关系、人物走位、场面 | 远 | 4~8 秒 |
| 全景 | full shot | 人物全身动作、肢体关系 | 中远 | 3~6 秒 |
| 中景 | medium shot | 对话、上半身动作 | 中 | 3~5 秒 |
| 近景 | medium close-up | 表情、情绪转向 | 近 | 2~4 秒 |
| 特写 | close-up | 细节、道具、眼神、手部动作 | 最近 | 1.5~3 秒 |

用法要点：

- **建立 → 逼近 → 细节 → 释放**。一段戏以宽景开场交代空间，逐级逼近情绪，高潮用特写，结尾可回到宽景留白。整片全是中景 = 没有镜头语言。
- 景别越小，可容纳的动作越少。特写里写「他跑过马路」是自相矛盾，只能写「瞳孔收缩」「指节捏白」。
  但「动作幅度小」不等于「画面静止」：特写必须有一个持续运动源，否则文生视频会交出一张会呼吸的照片。
  做法是**用局部写更大的动作**——手指因车身颠簸在方向盘上发抖、瞳孔随窗外掠过的灯光收缩、发丝被风压压向一侧、后视镜里逼近的车灯越来越大。禁止只写形容词（「神情凝重」「车里很安静」）而没有运动。
- 特写后直接切大远景，观众会失去方位感。一次最多跨 1 档，或中间垫一个全景/空镜过渡。

## 二、运镜：一镜一个运动，运动要有动机

| 中文（枚举值） | 英文 | 动机 |
| --- | --- | --- |
| 固定机位 | static shot | 让人看清画面内的运动；最稳，别怕用 |
| 缓慢推近 | slow push-in | 关注度上升、进入内心 |
| 缓慢拉远 | slow pull-out | 抽离、揭示环境、失落 |
| 横向移动 | lateral tracking shot | 展示空间层次、并列信息 |
| 环绕 | orbit shot | 强调人物的孤立或压迫 |
| 跟随 | tracking shot | 代入行动、保持速度感 |
| 手持晃动 | handheld camera | 混乱、纪实、临场 |
| 升格慢动作 | slow motion | 强调瞬间（唯一允许写 slow motion 的情况） |

- 固定机位不是「没有镜头语言」。文生视频里，画面内的动作 + 稳定的机位往往比花哨运镜更电影。
- 推近和拉远不要连着用同一镜；一镜里出现两个相反运动，模型会把画面拆成两段。
- 运镜必须与景别匹配：大远景适合横移/升格，特写适合缓慢推近或固定。

## 三、光线：方向 + 光比 + 色温，三样都要写死

- **方向**：主光从哪来（窗光侧逆、顶部实用光源、地面反光、远处灯塔扫光）。不写方向，模型就给一片均匀的棚拍光。
- **光比**：高对比（硬阴影、黑位重）＝ 紧张、黑色电影；低对比（柔光、雾）＝ 温柔、回忆。同一场戏内不许变。
- **色温**：暖（2700~3500K 钨丝/烛火/油灯）、中性（5600K 日光）、冷（6500K 以上夜色/月光/霓虹）。冷暖对撞是电影感的来源，但**只允许在一个统一基调上做局部对撞**（暖光人像 + 冷蓝环境）。
- **实用光源**：把光源写进画面里（灯、火、屏幕、车灯、霓虹），画面立刻有逻辑；只写「dramatic lighting」是空话。
- **体积感**：雨、雾、尘、烟让光可见；`volumetric light`、`dust particles`、`light shafts` 是性价比最高的一组词。

## 四、构图：给画面留层次

- **前中后景**：前景（雨帘、栏杆、肩膀、草）＋ 中景（主体动作）＋ 后景（环境、光源）。没有前景的画面最像游戏截图。
- **负空间**：主体偏一侧，留出大片空处，压抑或孤独感自然产生。
- **框中框**：门框、舷窗、后视镜、树影把人物框住。
- **视线方向**：人物看向画面哪一侧，那一侧就要有东西（或刻意空着）。
- **机位高度**：低机位＝压迫/崇高，高机位＝渺小/审视，平视＝平等/纪实。

## 五、镜头组接：让两镜「接得上」的四条匹配

> **方位词没有参照系，就没有方向。** 画面左 / 车身左 / 车道左是三件不同的事，混着写就必然出现「写的是左后方超车、拍出来是右前方对撞」。写方向前先定坐标系：画面用 `frame left`，纵深用 `toward / away from the camera`，物体用部位名词（`rear-right quarter panel` / `B-pillar`）。细则见 `video-prompt.md` 第三节。


1. **动作匹配**：上一镜抬手，下一镜手已抬到一半。这是 `same-take` 的核心。
2. **视线匹配**：A 看向右，切 B 时 B 看向左（正反打）。轴线（180° 线）不能越，越了观众就分不清谁在看谁。
3. **30° 原则**：换机位至少换 30° 角，否则看起来像跳帧。
4. **方向一致**：人物往右走，切镜后仍然往右（除非刻意表现迷失，且必须用镜头交代）。追逐戏里方向的连续性比构图漂亮更重要：车从画左冲向画右，切镜后仍要朝右，翻转一次观众就会觉得「它怎么又回来了」。

### 5.1 切点设计：为什么「上一镜意犹未尽，下一镜接不上」

问题不在提示词，在出口。AI 视频一镜一次生成，镜与镜之间没有真实的连续画面可以借，唯一能借的是**写在纸上的落点**。出口没有落点，下一镜无论换不换机位都只能重新建立画面，观感就是「断」。

出口只有三种收法：

| 收法 | 写法 | 下一镜怎么接 |
| --- | --- | --- |
| 动作顶点收 | 车头刚咬住前车、刀刚收、灯刚灭 | 切到反应 / 全景 / 后果，`hard-cut` |
| 动作交接收 | 动作做到一半，明确交给下一镜 | `same-take`（景别机位不许变，≤8 秒，连续 ≤2 次） |
| 遮挡甩镜收 | 主体走过柱子、镜头甩进暗部、雨幕盖住画面 | `hiddenCut: true`，景别可随便跨 |

出口必须给出**可接三要素**：主体在画面里的位置与大小、运动方向与速度、一个贯穿场景的背景锚点（同一条路、同一盏灯、同一个弯）。下一镜即使换机位也要重述这三要素：位置可以变，方向和锚点不能变。

反面：一镜结束在「车冲出画外」「尾灯消失在雨幕里」「画面全糊」。这种收尾单看很带感，但它把观众的眼睛也一起送出了画面，下一镜只剩重新开场一条路。

越轴要过桥：需要反向镜头时，先垫一个中性机位（迎面、背面、空镜、轮胎特写），或让主体在画面内完成转向，把方向交代清楚再切，不许直接左右对切。

衔接方式三态与本项目的接帧代价：

- `same-take`：同一次拍摄被切两刀，景别与机位都不许变。下一镜抽本镜末帧当首帧，接缝完全连续；代价是本镜不能用角色卡，单镜超过 8 秒人脸就开始漂。全片连续不超过 2 次。
- `hard-cut`：停机换机位（换景别、换角度、正反打）。同场景、同景别时仍接末帧（接缝不跳）；景别变了就把末帧降级成风格参考图，走角色卡 / 场景卡重新构图；换场景不接帧。
- `time-jump`：时间或地点跳转。不接帧。

一镜到底的景别变化只能靠运镜或遮挡转场实现，不能靠接帧：接帧把本镜第 0 帧钉死在上一镜的构图里，景别一变，观众看到的就是一次突兀的拉远 / 推近，而不是剪辑。真正在长镜头里换景别，用的都是遮挡——人物走过柱子 / 门框 / 走廊、镜头甩进暗部、雨幕或前景物件盖住画面（`hiddenCut: true`）。接缝被遮住，谁也不需要精确接住上一帧，景别因此可以随便跨。

## 六、节奏：镜头长度就是呼吸

- 全片镜头长度要有变化。舒缓段 6~10 秒，紧张段 2~4 秒；进入高潮时逐镜缩短，是全片最有效的一次节奏设计。
- 情绪曲线：`emotion` 1~5 逐镜推进，允许一次回落到 3 再冲 5（低谷 → 高潮）。全程 3 = 平；开场 5 之后再无处可去。
- 每镜必须有可见变化（位置、姿态、光线、物件）。没有变化的镜头，观众在看第二秒就离开了。

## 七、声音：模型愿意为一句台词配口型

- 台词一镜一句，10~20 字，不超过 `min(60, duration×4)` 字。
- `dialogue` 驱动口型，必须给 `speaker` 且人在画面里；`voiceover` 人物闭嘴；`none` 完全无口播。
- 需要环境声时，在 `videoPrompt` 末尾加一句（如 `heavy rain and distant thunder`），不要单独写一大段声音描述。

## 八、病历表：为什么生成的视频「不像电影」

| 症状 | 真正原因 | 处方 |
| --- | --- | --- |
| 画面漂亮但像屏保 | 没有主体动作，只有环境 | 每镜加一个可见动作，哪怕只是抬眼、呼气、灯灭 |
| 人物每镜长得不一样 | 每镜重新描述长相 | 复用角色 `promptEn`，逐字不改 |
| 主角的车每镜不一样（追车却很稳） | 追车有主体卡，主角座驾被当成道具，没有卡也没有 `promptEn` | 载具单独成卡：车型体量 / 车漆涂装 / 玻璃 / 轮毂轮胎 / 灯具 / 改装件 / 标识 / 动态；追逐双方各一张，并写进每镜 `characters` |
| 上一镜很带感，下一镜接不上 | 出口停在主体出画 / 全糊 / 动作做到一半，没有落点 | 出口三选一（顶点收 / 交接收 / 遮挡收），并写清画面位置、运动方向、背景锚点 |
| 追逐看起来像倒着跑 | 越轴或方向翻转，切镜后主体朝反方向运动 | 方向保持一致；要反向先垫中性机位，或让主体在画面内转向 |
| 写「左后方超车」，拍成「右前方对撞」 | 方位词没有参照系，画面左 / 车身左 / 车道左混着写 | 先写机位锚，再用「实体 + 部位」写接触点；左右一律带限定（`frame left` / `rear-left quarter panel`） |
| 画面接缝抽帧、抖一下 | 两镜不是同一个连续动作却接了帧 | 判断停机；同一场戏但景别变了，改用 `hiddenCut`，否则走卡片 |
| 一镜到底像一串生硬的推拉 | 靠接帧把跨景别的镜头粘起来 | 真一镜到底靠运镜；必须换景别时用遮挡转场 |
| 追逐 / 穿行戏变成一串碎片 | 按时长或景别切镜，串联性强的段落被拆开 | 镜数跟叙事断点走：同一空间、同一主体连续推进的段落放一个镜头，用 `beatSheet` 承载秒级推进 |
| 长镜头变成一段半死不活的慢动作 | `beatSheet` 写得太粗，或英文提示词没覆盖它的每一段 | 节拍按 2~5 秒一段写细；`videoPrompt` 用并列的现在分词按顺序覆盖每段，不写 `then` / `finally` |
| 动作发糊、后半段变慢 | 单镜超过 10 秒，里面塞的却是不连续的动作 | 先确认这一段是不是一条连续动作链：不是就拆镜，是就把 `beatSheet` 拆细、把动作幅度收小 |
| 画面自己乱加东西 | 提示词里堆了中文没写的元素 | `videoPrompt` 只做忠实英译 |
| 光一会暖一会冷 | 场景卡没写色温，逐镜自由发挥 | 场景卡写死光源方向与色温，逐镜复用 |
| 像 PPT 幻灯片 | 全中景 + 固定机位 + 每镜都在解释 | 景别递进、加前景、让画面承担叙事 |
| 结尾泄气 | 用总结性旁白收尾 | 最后留一个可承接的画面状态与余韵 |
